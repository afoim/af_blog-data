## 小坑

- 在 AMD Radeon Software 中，建议将所有设置设为默认。对于增值设置：如 **FSR 超分辨率**，**FSR 帧生成**，**AMD Fluid Motion Frames（AFMF）**，则将其关闭。因为在某些不支持这些设置的游戏中，AMD驱动仍然会向游戏声明或覆盖这些设置，可能会导致 **Low帧低** 或 **显示异常** 。推荐在游戏中设置这些选项（若目标游戏支持）

    ![](/img/9060xt-index.png)
- **【勘误】伪影的锅不在 FSR，在 AFMF。** 本文早先把下面两张图的 **伪影** 归咎于 **FSR 帧生成**，这是错的。复测后确认，罪魁祸首是 **AFMF**。**FSR 超分辨率** 和游戏内的 **FSR 帧生成** 都很好用，该开就开

    真正要关掉的是 **AFMF（AMD Fluid Motion Frames）**。它和游戏内的帧生成**不是一回事**：游戏内的帧生成拿得到引擎给的运动矢量和深度信息，知道哪些像素属于 UI，会把界面**排除在插帧之外**；而 AFMF 是**驱动层**的，它只看得到最终合成好的整张画面，于是**连字幕和 HUD 一起插**——下面两张图里对话框和字幕的重影，就是这么来的

    ![](/img/9060xt-afmf-toggle.png)

    ![](/img/9060xt-4fcd082a176b6f5f82e516a77b0a7859.png)

    ![](/img/9060xt-d339d33e7a92ac8a331c535750c649b8.png)

    **AFMF 无论帧数高低都不建议开**，这种重影是它的工作原理决定的，不是调一调参数就能避开。连 AMD 自己的提示弹窗都要给它加一堆前提条件——「帧生成可能会造成额外的延迟，并且在快节奏竞技游戏中可能导致无法获得最佳体验」

    ![](/img/9060xt-afmf-dialog.png)

    更坑的是 **HYPR-RX**（AMD 的一键游戏预设）会**默认把 AFMF 打开**，很多人是在完全不知情的情况下吃下这份重影的。用过 HYPR-RX 就记得回去单独把 AFMF 关掉
- **游戏里 GPU 占用 99%、功耗却离 TDP 差一大截？去关掉「硬件加速 GPU 计划」。** 典型症状是：进游戏后 GPU 占用顶着 **99%** 但**功耗远不到 TDP**，反倒是切到游戏的**纯 UI 界面**（比如设置页）时功耗**顶着 TDP 跑**。占用满而功耗上不去，说明 GPU 大部分时间在**空转等活**，并不是真的在满负荷渲染

    打开 Windows 设置 → **系统 → 屏幕 → 显示卡 → 高级图形设置**，把 **硬件加速 GPU 计划** 关掉。改完**需要重启游戏**才会生效

    ![](/img/9060xt-hags.png)

## 详细性能指标

> 以下内容的设置倾向为 **能用 FSR 超分辨率 就用**，若游戏不支持则**强算**。除**特别标注**外，均为**未启用任何帧生成**（含 AFMF）的原生渲染帧率；异环一条为**开启 FSR3 帧生成后**的数值，不与其它条目直接可比。测试分辨率为 **2K**，具体值为上一节提到的测试平台使用的显示器

> [!tip]
> 对于低显存的显卡，在游戏中频繁更改画质设置可能会导致显存内临时存放多个不同质量的材质，导致 **爆显存** ，主观体验为：**极低的帧率，游戏画面卡住，游戏程序崩溃** 。建议在进行画质调整后，静等一段时间，等待旧的材质在显存中被清理释放，或者重启游戏后再进行下一次的画质调整。否则会一直处于：**加载新材质 --> 爆显存 --> 垃圾清理未完毕 --> 加载新材质 --> 继续爆显存** 

- **绝区零** ：画质拉满**≈130FPS**（不支持也不接受任何FSR相关设置）
- **明日方舟：终末地** ：画质拉满**≈80FPS**（不支持也不接受任何FSR相关设置。若 **强制全局启用FSR的任何设置** ，会频繁出现顿卡，导致Low帧低）
- **鸣潮：** 画质拉满**≈100FPS**，若启用FSR超分辨率，则**≈170FPS**
- **卡拉彼丘**： 最低画质靶场顶着**480FPS**跑（FPS游戏，帧数＞画质，还打不死人就肯定你的问题）
- **异环** ：平衡画质**≈100FPS**，若启用FSR超分辨率，则**≈170FPS**。该游戏在更高一档预设画质中会**新增反射相关的设置**，且默认会分配 **SSR** 选项 ，会导致帧数断档性质的下降，同时画质也会有**质的飞跃**，只开超分的话只剩**60FPS**左右

    **【更正】** 此前据此判断「为了最终体验，不再拉高画质」，实测是**可以拉满的**——把游戏内的 **FSR3 帧生成** 一起打开就行。**原画**画质 + **FSR3 超分（质量档）** + **FSR3 帧生成**，2K 下平均 **110.3 FPS**、95th 百分位帧时 **10ms**，AMD 性能报告给的评级是**出色**。这也是「游戏内帧生成值得开」最直接的例子——它和上面那个要关掉的 AFMF 是两码事
